# PT Helper

[Tải bản mới nhất](https://github.com/thinhly-lifetechvn/pt-auto-releases/releases/latest)

Repository này chỉ phân phối bản phát hành Windows. Mã nguồn được quản lý riêng trên GitLab.

## Cài bản đầu có nút Cập nhật

1. Tải **PTHelp.exe** trong phần **Assets** của bản mới nhất.
2. Dừng tác vụ và tắt PT Helper, thay exe trong thư mục đang sử dụng rồi mở lại.
3. Giữ config.json và các file dữ liệu riêng trong thư mục đó.

## Các lần cập nhật sau

1. Bấm **Cập nhật** trên bảng điều khiển. App tải nền và kiểm SHA-256; Auto vẫn chạy.
2. Tải xong, dừng Auto/Semi/Assist và các tác vụ rồi bấm **Cập nhật & mở lại**.

Updater chỉ thay exe; giữ cấu hình, model, mẫu, nhật ký và file Telegram riêng.
Máy nhận không cần đăng nhập hoặc token GitHub. App không tự dừng nhân vật để cài update.

Mỗi release có PTHelp.exe và version.json. Các bản mới chỉ được công khai sau khi hai asset tải lên hoàn tất và khớp SHA-256.
